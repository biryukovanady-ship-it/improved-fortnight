# Таблица вакансий

[vacancies.csv](vacancies.csv) служит шаблоном и текущим реестром. Первая строка содержит названия столбцов; примеров и реальных вакансий пока нет. Новые записи добавляйте со второй строки.

## Открыть и сохранить в Excel

1. Скачайте CSV через кнопку Raw или Download raw file на странице файла.
2. В Excel выберите **Данные → Из текста/CSV**, кодировку **UTF-8** и разделитель **запятая**. Так кириллица и столбцы будут прочитаны корректно независимо от настроек компьютера.
3. Для ID и URL задайте текстовый тип, для зарплаты и численности числовой, для дат тип «Дата» с отображением `гггг-мм-дд`. Фильтры можно включить через **Данные → Фильтр**.
4. При сохранении выберите **CSV UTF-8**. Проверьте разделитель: Excel с русскими региональными настройками может записать точку с запятой. Если это произошло, пересохраните файл с запятой в редакторе, поддерживающем выбор разделителя CSV. Не заменяйте все точки с запятой вслепую, они могут быть частью комментария.
5. Загрузите обновлённый CSV в репозиторий через Add file → Upload files и проверьте изменения. Локальная копия Excel и GitHub автоматически не синхронизируются.

CSV хранит данные без оформления, фильтров и выпадающих списков. В GitHub его можно редактировать как текст. Поля с запятыми, кавычками или переносами строк заключайте в двойные кавычки; кавычку внутри поля удваивайте.

## Столбцы

| Столбец | Что записывать |
| --- | --- |
| ID | Постоянный идентификатор: `VAC-0001`, `VAC-0002` и далее. Не менять при сортировке. |
| Компания | Название работодателя из объявления. |
| Вакансия | Название позиции из объявления. |
| Отрасль | Отрасль работодателя; если не установлена, «Не указано». |
| Численность | Точное опубликованное число сотрудников. Если известен только диапазон, оставить пустым и привести диапазон в комментарии. |
| Источник численности | URL страницы или отчёта, подтверждающего число или диапазон. Дату источника указать в комментарии. |
| URL вакансии | Прямая ссылка на основное объявление. |
| Тип источника | «Сайт работодателя», «hh.ru» или «Другое». |
| Дата публикации | Дата первичной публикации по источнику; пусто, если неизвестна. Подтверждение даты указать в карточке вакансии. |
| Дата обнаружения | Когда позицию впервые внесли в трекер. |
| Дата проверки | Когда в последний раз проверили объявление и условия. |
| Формат работы | Например, «Удалённо из РФ», «Гибрид», «Офис» или «Требует уточнения». Уточнить ограничения по стране и часовому поясу. |
| График | График из объявления, например «5/2», либо «Не указано». |
| Зарплата от | Опубликованная нижняя граница месячной зарплаты, только число. Для фиксированной суммы заполнить обе границы. |
| Зарплата до | Опубликованная верхняя граница месячной зарплаты, только число. Если есть лишь одна граница, вторую не придумывать. |
| Валюта | Например, `RUB`, `USD`, `EUR`. |
| Зарплата до/после НДФЛ | «До НДФЛ», «После НДФЛ» или «Не указано». Для другой налоговой системы дать пояснение в комментарии. |
| Английский | Требование объявления: «Не требуется», «Переписка», «Разговорный» или «Не указано»; уровень уточнить в комментарии. |
| Командировки | «Нет», «Да» или «Не указано». |
| Соответствие | «Подходит», «Требует уточнения» или «Не подходит». При неизвестных существенных условиях использовать «Требует уточнения». |
| Приоритет | «Высокий», «Средний» или «Низкий». Причину высокого приоритета указать в комментарии. |
| Статус | Одно из значений в [основном README](../README.md#статусы-таблицы). |
| Дата отклика | Дата фактической отправки; при подготовке оставить пустой. |
| Issue вакансии | Полный URL основной карточки в этом репозитории. |
| Issue отклика | Полный URL карточки отклика. До её создания оставить пустым. |
| Issues собеседований | Полные URL карточек этапов, разделённые пробелом. |
| Следующее действие | Конкретный шаг, например «Уточнить условия удалёнки» или «Проверить ответ». |
| Срок следующего действия | Дата следующего шага; для завершённой записи можно оставить пустой. |
| Комментарий | Причина приоритета или несоответствия, неподтверждённые условия, дополнительные ссылки. |

## Общие правила

- Даты записываем как `YYYY-MM-DD`. Встречи и сроки с точным временем ведём в issue с указанием часового пояса. Основной часовой пояс трекера: `Europe/Saratov`, UTC+4.
- Зарплата и численность записываются без пробелов, валютных знаков и единиц измерения. Если период выплаты отличается от месяца, месячную сумму не вычисляем без оснований: указываем исходные условия в комментарии, а границы оставляем пустыми.
- Сначала заполняйте ID, компанию, позицию, URL, тип источника, даты обнаружения и проверки, соответствие, приоритет и статус. Для активной записи нужны также следующее действие и его срок.
- Проверка свежести: дата публикации не позже даты подборки, а разница между ними не превышает 21 день. Пустая дата требует уточнения; не заменяйте её датой проверки. Возраст вакансии сам по себе не завершает уже начатый отклик.
- Неизвестные числовые значения и даты остаются пустыми. Для текстовых условий используйте «Не указано» или «Требует уточнения».
- Таблица содержит актуальное состояние. Подробная история и результаты этапов хранятся в связанных issues.
